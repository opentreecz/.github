## About Us

We are an open-source community based in the Czech Republic, working on
infrastructure, automation, and developer tooling. Our projects span:

- **Kubernetes & Helm** -- K3s bare-metal clusters, Helm charts, GitOps workflows
- **Package Management** -- OpenRepo for managing deb, rpm, and generic package repositories
- **Networking** -- IPv6 testing tools, OpenWrt configurations, mail reverse proxies
- **Developer Tools** -- Terminal emulators (Ghostty, Kitty, Alacritty), IoT relay control
- **Gaming & Media** -- Minecraft server Helm charts, PlayStation remote play
