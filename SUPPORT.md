# Support

Looking for help with an opentree.cz project? Here is how to get support.

## Documentation

Visit our project website for full documentation:

- [opentreecz.github.io](https://opentreecz.github.io/)
- [Repository catalog](https://opentreecz.github.io/repositories)

Each repository also has its own README with project-specific instructions.

## Getting Help

### GitHub Issues

If you have found a bug or want to request a feature, please open an issue in
the relevant repository:

- Browse all repositories at
  [github.com/orgs/opentreecz/repositories](https://github.com/orgs/opentreecz/repositories)
- Use the **Bug Report** or **Feature Request** issue templates provided

### GitHub Discussions

For general questions, ideas, or community discussion, use GitHub Discussions
if available in the specific repository.

## Reporting Security Issues

**Do NOT report security vulnerabilities through public issues.**

Please read our [Security Policy](SECURITY.md) for instructions on how to
report vulnerabilities responsibly.

## Contributing

Want to contribute? Read our
[Contributing Guide](CONTRIBUTING.md) to learn about our workflow, coding
standards, and how to submit a pull request.

## What to Expect

- **Issue responses**: We aim to respond to new issues within **5 business days**.
- **PR reviews**: We aim to review pull requests within **7 business days**.
- **Availability**: This is a community-driven project maintained by volunteers.
  Response times may vary.

---

Thank you for being part of the opentree.cz community.
